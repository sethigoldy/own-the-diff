---
name: guided-review
description: Guide a developer through frozen changes without speaking for the human approver.
---
Read cor status --json and the selected unit's evidence using cor review --unit ID --json or inspect its browser link. Explain the intended behavior, affected repositories, unresolved findings, tests and current capture. Give the developer the browser or terminal link for their explicit decision. After a code change, refresh and inspect stale items. Use cor verify for current readiness and cor export to prepare the handoff. Only the developer confirms approval or dismisses a finding.
